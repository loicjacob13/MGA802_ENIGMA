# Mini-Projet A : Chiffrement César & Enigma César
### MGA802 - Introduction à la programmation avec Python
### École de Technologie Supérieure (ÉTS) 

## Description du projet
Ce projet consiste à coder en Pythonn un programme capable de chiffrer et de déchiffrer des textes, à l'aide de deux algorithmes :
1. **Le Chiffrement de César** : clé = 1 entier.
2. **Le Chiffrement Enigma César** : clé = 3 entiers.
